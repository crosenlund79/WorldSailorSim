# Audio: buses and replacing sounds

The sound effects and ambience are temporary placeholders, generated by
`tools/generate_placeholder_audio.py` into `assets/audio/placeholder/`. Replacing
one needs no code changes. The music is the game's own soundtrack (see
[The soundtrack](#the-soundtrack) below).

## Buses

Defined in `default_bus_layout.tres`:

| Bus | Carries | Volume slider |
|---|---|---|
| Master | everything | Settings → Master |
| Music | music | Settings → Music |
| Ambience | looping background sound per area (deck, cabin) | Settings → Ambience |
| SFX | game sounds: interactions, engine, the companion's purr or panting | Settings → SFX |
| UI | button clicks | Settings → UI |
| Outside | the weather heard aboard (water along the hull, rain, thunder); sends to Ambience, with a low-pass filter that muffles it below deck | Ambience |
| Wind | the wind (breeze and storm wind); sends to Outside, so it is muffled below deck too (I022) | Settings → Wind (100 % = the earlier balance) |

`AudioManager` (`src/audio/audio_manager.gd`, an autoload) plays sounds on the
right bus; scenes only say *what* to play. `SettingsManager` sets the bus volumes
(0% mutes). Settings has a **Test** button per bus.

## Replace a sound (shortest way)

1. Export your sound as **WAV** (16-bit PCM, 44.1 or 48 kHz) or **OGG Vorbis**.
2. **Same format:** overwrite the file in `assets/audio/placeholder/` with the
   same name, for example a real purr as `companion_purr.wav`.
3. Let Godot re-import it (focus the editor, or run
   `godot --headless --path . --import`) and run the game.

To use a different name, folder or format (for example `.ogg`):
1. Put the file in `assets/audio/`.
2. In Godot, select the node or scene that uses the sound (see the table) and
   drag your file onto the property in the Inspector. For the companion, open a
   cabin scene such as `src/vessels/starling_33/cabin.tscn`, select the `Companion`
   node and set **Purr Sound** or **Dog Sound**.
3. Save the scene.

Companion sounds are set per cabin scene, so after changing them in the
Inspector, do the same in all three cabins (or change the default in the
script's `@export` line). Overwriting the file with the same name changes all
three at once.

## The soundtrack

Three original pieces in `assets/audio/music/`, chosen by the `MusicDirector`
autoload (`src/audio/music_director.gd`):

| When | Piece |
|---|---|
| Night at the boat (the game's own sun, not the computer clock), anywhere | *Lanterns Across the Water* |
| Day, underway on deck (sailing, Long Passage) | *The Wind Knows the Way* |
| Day otherwise: harbour, cabin, at anchor, the title screen | *Home Upon the Waves* |

How the music moves between pieces:
- The pieces crossfade over five seconds.
- A new situation must last three seconds before the music follows it.
- A piece plays at least 25 seconds before it changes again.
- Day and night never switch while fast passage time is running.
- A piece the game returns to resumes at the start of its phrase, not from the top.
- Windows, the chart and the pause menu change nothing.
- With the Music volume at 0, the players are paused.

To change the music:
- **Replace a piece.** Put a new `.ogg` of the same name in
  `assets/audio/music/` (stereo, looping from its end back to its start). You
  can delete its `.json` sidecar, and the piece then resumes from its start.
- **Revise a piece.** Edit its score in `tools/music/tracks/`, then run
  `python3 tools/music/build.py`; see [tools/music/README.md](../tools/music/README.md).
- **Compare without music.** Run the game with `-- --no-music` to silence it.

## Loops

- **Ambience** loops by restarting when it ends, so any file works. The
  soundtrack's OGG files loop seamlessly (`loop=true` in their `.import`).
- **The engine** uses two loops that play in step and cross-fade between deck
  and cabin. Their WAV imports use forward looping: `edit/loop_mode=2` in
  `engine_hum.wav.import`. A replacement engine sound must:
  - loop seamlessly;
  - have the same length in both files;
  - keep that loop setting (Import dock → Loop Mode: Forward → Reimport).
- **The storm wind** (`storm_wind.wav`) also uses forward looping
  (`edit/loop_mode=2` in `storm_wind.wav.import`) and must loop seamlessly. Its
  volume follows the wind at the boat; see [WEATHER.md](WEATHER.md).

## Check it

- Settings has a **Test** button for Music, Ambience, SFX and UI.
- In the game: pet the cat (E), motor out of the harbour (engine on deck, quieter
  below), and walk between deck and cabin (ambience).
- The automated tests check that the companion sound plays on the SFX bus,
  that the engine loops follow the propulsion state, and that the storm-wind
  loop plays in a gale and stops when the wind drops (`test_weather_ui`).
