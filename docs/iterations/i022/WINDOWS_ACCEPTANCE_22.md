# I022 Windows acceptance checklist (0.109a)

**Status: pending.** This checklist is for the Captain to fill in after his own trial on Windows. Nothing here has been run on Windows yet.

## Setup

1. Download the release ZIP (`release/i022`).
2. Extract it.
3. Open `project.godot` in Godot 4.7 and run.

Step 1 needs an old save from 0.108a.

To see the First Voyage offer in step 8, start with no `[academy]` section in `settings.cfg`. A computer that has never run 0.109a has none.

## Checks

| # | Check | Expected | Result |
|---|---|---|---|
| 1 | Load a save made with 0.108a | It loads where it was, with the same money. Every boat is still yours, and the boatyard says "Move aboard" for each. No First Voyage offer appears. | |
| 2 | Start the game | The boot splash and the loading screen are the main menu's navy, with the logo. There is no bright flash. The menu shows "Version 0.109a". | |
| 3 | Settings → Audio | There is a **Wind** slider next to Ambience. Its test sound is a breeze. Turning it down quietens the wind and storm sounds but not the rain or the sea. | |
| 4 | New Game | Relaxed, Standard and Seasoned Captain are offered (Standard is chosen). Each has a short description. A Seasoned game starts with €7,000. | |
| 5 | Pause menu → Difficulty… | It shows the current level. Choosing another and pressing Apply changes it from now on; the money is unchanged. | |
| 6 | A boatyard (e.g. Copenhagen) | Each boat shows a price. A boat you cannot afford says how much is needed. A boat you buy says "Move aboard" afterwards. | |
| 7 | Pause menu → Captain's Handbook (or F1) | 27 pages in chapters, with a search box. Searching "anchor" (in Danish, "anker") finds the anchoring page. The keys named on the pages are the real ones. Close and Esc both close it. | |
| 8 | First new game on this computer | You are asked "Your first voyage": Begin or Skip. Begin shows a small card in the lower right corner that ticks off each step as you do it (walk, Q, L, deck, chart, course, set sail, 5×). "Skip the First Voyage" works at any time. | |
| 9 | Tips | The first time underway, in harbour, at a bite and so on, a short tip appears lower right. It never covers an open window or a red warning. "Got it" closes it, and "Read more" opens its Handbook page. Settings → Tips turns tips off. | |
| 10 | Cabin → Q → Write a postcard | You choose the subject, the words and the layout, and the preview shows the card. It says it takes about 2 hours. Make and publish fades, the clock counts, and you come back at 1×. The card is in the Scrapbook. A new subject gives +3 renown; the same subject again gives none. | |
| 11 | Cabin → Q → Work on your little game | Each task shows its hours (2–4 h). You must pick an answer first. A session fades, the clock counts, and the result is reported. After a few sessions a milestone appears in the devlog with +4 renown. | |
| 12 | Interrupt a pastime: start a postcard about an hour before arriving | The fade stops at the arrival ("Interrupted …"). The postcard is kept, and finishing it later takes only the time left. | |
| 13 | Remote work (moored) | It now fades and counts the hours like sleep. The pay is as before. | |
| 14 | Starling 33 (Wing 33) cabin, moored, by day | Three small windows on each side of the saloon walls. To starboard you see the harbour's houses, to port open water with a distant shore. Walking past a window turns its view. The frames and furniture stay in front. | |
| 15 | The same at dusk, at night, and underway | Warm low light at dusk; dark with stars at night; open sea underway; rain streaks in rain. | |
| 16 | Deck water | Slightly softer and less solid than before. Moored, a hint of sandy bottom shows. Night and storms still look different. | |
| 17 | Settings → Language → Dansk | The Handbook, tips, postcards, little game, difficulty and prices are all in Danish. | |
| 18 | General feel | No new stutters in the cabin, at the chart, or at dawn and dusk. | |
