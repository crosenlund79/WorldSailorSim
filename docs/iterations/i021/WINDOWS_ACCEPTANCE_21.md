# I021 Windows acceptance checklist (0.108a)

**Status: pending.** To be filled in by the Captain after his own trial on
Windows. Nothing here has been run on Windows yet.

Download the branch ZIP (GitHub → Code → Download ZIP), extract it, open
`project.godot` in Godot 4.7 and run. An old save from 0.107a can be used for
step 1.

| # | Check | Expected | Result |
|---|---|---|---|
| 1 | Load a save made with 0.107a | It loads where it was; the boat, money, catch and cabin things are unchanged | |
| 2 | Main menu | "Version 0.108a" | |
| 3 | Moor in Copenhagen (or load a save there) | Nyhavn's houses beyond the quay, as before | |
| 4 | Sail (or use Long Passage) to a new harbour, e.g. Valletta or Dingle | On arrival a small card appears with a picture, "Arrived in …" and one sentence about the place; it fades by itself and nothing is blocked | |
| 5 | On deck in that harbour | The quay is the same; beyond it the harbour's own view (Valletta: limestone bastions; Dingle: grey stone houses) | |
| 6 | Navigation chart, zoom to Malta | A small brass star beside Valletta's pin; selecting Valletta shows "Special harbour: …" in the details | |
| 7 | Chart at night (Harbor Dusk) | The star is still clear; nothing overlaps the boat or labels badly | |
| 8 | Dreamer's Map | Visited harbours keep their red pins; special harbours show the star | |
| 9 | Settings → Language → Dansk; open the chart and select Kapstaden (Cape Town) | Danish name and sentence; "Særlig havn: …" on a special harbour | |
| 10 | Fish off a new harbour (e.g. trolling near Lunenburg, Zanzibar or Langkawi) | New fish can bite (striped bass, Spanish mackerel, giant trevally …), each with its own picture that blinks | |
| 11 | Sell a new fish at a fishmonger | It sells once, at a fair price | |
| 12 | Chandlery: buy the model ship, the jar of sea glass and the barometer | Each costs a little and appears in the cabin ("Make it home"), never over a station | |
| 13 | Switch boats at a boatyard and back | Each boat keeps its own cabin things | |
| 14 | General feel | No new stutters when opening the chart or arriving in harbours | |

Notes for the Captain: the harbour picture on the deck sits at the bottom edge
of the screen (as Nyhavn always has); the arrival card shows more of it.
